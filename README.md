# Real-Time-Multimedia-Analysis-and-Annotation-Platform

Introduction
Accurate segmentation of speech data plays a crucial role in applications such as speech language pathology, speech recognition, and assistive communication tools. Manual annotation is labor intensive and time consuming, especially when dealing with long, continuous recordings. An automated method can save time, reduce human error, and allow for broader application in clinical and educational settings. This project builds on recent advances in deep learning, particularly transformer based models, for sequence classification and audio processing.
This project focuses on the automatic segmentation of video/audio samples into segments based on pronunciation patterns, with applications in speech therapy, language learning, and clinical linguistics. The challenge lies in accurately segmenting the video/audio samples into segments corresponding to target pronunciation patterns specifically vowel sounds like "ahh" and "ehh," Rainbow Passage readings, and other sentences or passages while distinguishing these from irrelevant speech, such as cross talk in the middle and silence. This project addresses this challenge by first creating an annotated dataset using a custom built annotation tool, followed by the development of an automatic segmentation tool to process the data.
The motivation for this project stems from clinical needs in throat cancer center, where accurate monitoring of patient pronunciation is critical. This project leverages deep learning, specifically Wav2Vec2 transformer models, to create an end to end pipeline for automatic segmentation.
1.1	Project Objectives
The primary objective of this project is to design and implement an automated system capable of segmenting and classifying clinically relevant speech patterns from recorded audio and video samples. The overarching goal is to minimize the manual effort required in clinical voice analysis by automatically detecting and isolating meaningful speech segments while filtering out non-speech regions such as silence and background noise.
The first objective focuses on dataset creation, involving the development of a labeled collection of audio and video samples that encompass both positive and negative classes. The positive classes include sustained vowel sounds (“ahh” and “ehh”), Rainbow Passage readings, and other structured reading tasks, while the negative classes represent silence, crosstalk, and irrelevant acoustic segments. This dataset serves as the foundation for model training and evaluation.
The second objective is the development of an automatic segmentation tool utilizing the Wav2Vec2 transformer based architecture. The tool processes clinical recordings to identify, segment, and categorize distinct speech events, ensuring that only clinically meaningful portions are preserved for analysis.
The final objective emphasizes model evaluation and insight generation. The segmentation model is tested on unseen recordings to assess its accuracy, robustness, and generalization capability. Based on these findings, the study provides recommendations for refining the model and enhancing its applicability in clinical pronunciation assessment and automatic segmentation research.

1.2 Technical Objectives
The technical objectives of this project focus on implementing a complete and functional framework for automated clinical speech segmentation. The first objective is to create a well structured dataset consisting of annotated audio and video clips representing four classes: “ahh,” “ehh,” “rainbow,” and “negative.” This dataset forms the foundation for model training and evaluation.
The second objective involves training a Wav2Vec2 based transformer model for sequence classification. The model is designed to recognize and differentiate between sustained vowel sounds, Rainbow Passage readings, and non speech segments such as silence or crosstalk.
The third objective is to develop an inference pipeline capable of processing .mp4 input files and automatically generating segmented .mp3 and .mp4 clips corresponding to the detected speech events. The system applies clinically defined duration based rules, retaining “ahh” and “ehh” and “rainbow” segments.
Finally, the project aims to provide accessible tools for clinicians and researchers through both a Google Colab based Streamlit web interface, and an optional GUI based desktop version for local use. These interfaces make the model’s segmentation functionality easily accessible without requiring extensive technical knowledge.
